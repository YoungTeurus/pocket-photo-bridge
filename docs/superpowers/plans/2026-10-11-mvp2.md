# Pocket Photo Bridge MVP 2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline implementation; independent research and platform tasks may use superpowers:dispatching-parallel-agents. Finish with one independent whole-branch review.

**Goal:** Direct local test-image and Sony-preview printing over Xiaomi Classic Bluetooth, with actionable diagnostics when a device token is unavailable.

**Architecture:** Pure Kotlin `printer` protocol plus Android `printing` transport/preparation/UI, separate from the unchanged Sony receiver. Use a durable conservative print-job guard and explicit one-copy confirmation.

**Tech Stack:** Existing Kotlin 2.2.21 / AGP 8.13.2 / Gradle 8.13 / API 29–36; JUnit and Robolectric; small JVM JSON dependency and Android EXIF support if needed.

**Spec:** `docs/superpowers/specs/2026-10-11-mvp2-xiaomi-design.md`; Issue #3.

## Global constraints

- Preserve PR #2's Sony transfer, preview and Gallery export.
- No Xiaomi Home/cloud/Linux port; no invented keys, identities or authentication.
- SKU TEJ4007CN is user-reported; firmware/profile compatibility remains unvalidated.
- Tokens are local memory only; diagnostic exports contain fixed codes/counts only.
- One explicitly confirmed copy; no automatic job retries or success from idle alone.

## Review focus

- Process death or lost reply after job reservation must prevent accidental duplicate printing.
- Device selection and permission dialogs must not clear the source Sony JPEG.
- Unknown firmware/status must stop rather than invoke a different protocol.
- Bluetooth connect/read/write must be cancellable and time-bounded off the UI thread.
- EXIF mirrors/rotation and fit/crop must preserve the original file and produce a bounded baseline JPEG.
