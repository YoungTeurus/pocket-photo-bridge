# Synthetic Sony selection fixture

sony-selected.jpg is a project-generated 256x384 RGB quadrant/border/circle chart, encoded as baseline JPEG90 with Pillow. It contains no personal photo, camera identifier or EXIF credential. SimulatedSony advertises only this synthetic selection; neither network nor radio access is used. sony-selected-next.jpg fills the center circle to provide a different synthetic photo for manual recovery.
